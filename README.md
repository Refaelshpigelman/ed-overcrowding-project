# חיזוי זמן טיפול בקריאה במחלקת מיון | ED Wait-Time Prediction (Neural Network)

פרויקט גמר במדעי הנתונים, בשיתוף מרכז רפואי מאיר.
**אלסיה אקולנקו • רפאל שפיגלמן**

מערכת לחיזוי זמן הטיפול בקריאה בודדת במחלקת מיון (שלוש קטגוריות: קצר/בינוני/ארוך), באמצעות רשת נוירונים (MLP), מבוססת על כ-460 אלף רשומות תפעוליות היסטוריות ממחלקת המיון של בית חולים מאיר (נובמבר 2023 – פברואר 2025).


## תוצאה מרכזית

המודל הטוב ביותר מתוך 24 קומבינציות שנבדקו בפועל (שכבה חבויה אחת, 8 נוירונים, Sigmoid, learning rate=0.005):

| מדד (macro-average) | ערך |
|---|---|
| AUC-ROC | 0.8025 |
| F1 | 0.6276 |
| Precision | 0.6381 |
| Recall | 0.6335 |
| Accuracy | 0.6335 |

**ממצא מרכזי**: 6 מתוך 24 קומבינציות קרסו לחלוטין (AUC=0.5, F1=0.1667 — שווה ערך לניחוש אקראי בין 3 קטגוריות) — בעיקר ברשת ה-8-שכבות, ואף בקומבינציה אחת ב-4 שכבות. תופעת Vanishing Gradient קלאסית. רשתות רדודות (1–2 שכבות) הניבו את הביצועים הטובים והיציבים ביותר. התוצאות המלאות שמורות ב-`docs/nn_grid_results.csv`.

## תוכן הנוטבוק

הנוטבוק `ED_full_project_with_NN.ipynb` בנוי משני חלקים רציפים:

**חלק א׳ — טעינה, ניקוי ו-EDA**
טעינת הדאטה הגולמי, `preprocess_data` (ניקוי timestamps, מיפוי מחלקות/סטטוסים), וניתוח EDA תפעולי: זמני סגירת בקשות ניקיון, התפלגות סוגי בקשות, חדרים עמוסים, וניתוח Bottleneck Rooms.

**חלק ב׳ — חיזוי זמן טיפול עם רשת נוירונים**
1. בניית ה-Label: זיווג אירועי פתיחה (`required`) עם אירועי סגירה (`satisfied`/`taken`) לפי (מחלקה, חדר, סוג טיפול), וחישוב זמן ההמתנה בפועל.
2. Features: `day_of_week`, `hour`, `department`, `room`, `requirement` — כולם נגזרים ישירות מהדאטה, **ללא נתונים סינתטיים**.
3. Label תלת-קטגורי: short/medium/long לפי שלישונים (terciles) של זמן ההמתנה — כל קטגוריה כ-33.3% מהדאטה (`pd.qcut`).
4. גריד של **24 אימוני MLP** (multi-class): 4 ארכיטקטורות × 3 learning rates × 2 פונקציות אקטיבציה (ReLU/Sigmoid), עם Cross-Entropy Loss רב-קטגורי.
5. טבלת תוצאות מלאה (AUC-ROC macro, F1 macro, Precision macro, Recall macro, Accuracy לכל הרצה) + ויזואליזציה השוואתית.

## הרצה

הנוטבוק נבנה לעבודה ב-Google Colab:

1. פתחו את `notebooks/ED_full_project_with_NN.ipynb` ב-Colab.
2. הריצו את תא ה-upload והעלו את `data/ED_full_data_2.csv`.
3. **Runtime → Restart and run all**.

⏱️ הריצה המלאה (כולל 24 אימוני הרשת) לוקחת כ-5–6 דקות.
